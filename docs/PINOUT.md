## SPI и силовые выходы

SPI1: PA5 SCK, PA6 MISO, PA7 MOSI (AF5). PA4 — STCP защёлка внешних регистров. Общая SPI1 используется силовыми выходами и четырьмя L6474; нужен один владелец шины. Legacy: CPOL1/CPHA1 (mode3), prescaler2 для выходов, prescaler32 для L6474. Выходы НЕ являются двадцатью непосредственными GPIO STM32.

Восемь уникальных насосных подключений из этих двух профилей получить нельзя. Каналы 5–8 и расширение 16+ требуют отдельной подтверждённой схемы и привязки.
